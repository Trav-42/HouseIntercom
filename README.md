WIP - THIS IS A WORK IN PROGRESS!
This project currently connects two M5StickCPlus2 devices, with the SpeakerHat2 attached, and attempts to send audio data between them via WiFi.


Please look at the "CurrentClientServerFiles" folder for the most updated code.

This project requires downloading the M5Unified and M5StickCPlus2 libraries through PlatformIO.

Insert the code you would like to put onto the M5StickCPlus2 devicee into main.cpp; from there you can build and download the code to the device.
